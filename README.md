# WritersLogic product hub

The one-screen hub at [writerslogic.github.io](https://writerslogic.github.io/) links to bluepencil, Scrivener MCP, Holographic Memory, and WritersProof. Each tile is a normal link. A short local animation expands the selected tile before navigating; reduced-motion users navigate directly.

The site is plain HTML, CSS, and JavaScript in `site/`. GitHub Pages publishes that directory on pushes to `main`.
